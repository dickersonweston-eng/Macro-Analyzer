# Macro Analyzer

A Geode mod for Geometry Dash that analyzes and converts macro/replay files directly in-game — an in-game companion to the [GD Macros](https://github.com/dickersonweston-eng) desktop app.

## Features

- Pick and parse `.gdr2` macro files from within GD
- View replay stats: author, level, duration, frame count, coins, and more
- Support for `.gdr` and `.json` formats coming soon
